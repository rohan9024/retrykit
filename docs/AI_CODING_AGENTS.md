# AI coding agents

Runtime package: `npm i @rohan9024/retrykit`.

Agent skill: `npx skills add rohan9024/retrykit --skill retrykit`.

The skill is guidance for coding agents; it is not a substitute for installing the runtime package. Cursor, Claude Code, Codex, Copilot, Windsurf, Cline/Roo, Gemini CLI, and other agents can use `AGENTS.md` plus `skills/retrykit/SKILL.md`. Agents should inspect existing retry logic, obtain dependency approval, use the detected package manager, and verify with the repository checks.
